จบด่านเมื่อไร คะแนนจะวิ่งเข้าตาราง `scores` ของโปรเจกต์ `vgurqbcbovgeppvdwizr.supabase.co`
ซึ่งเป็น**ชุดเดียวกับเกมภารกิจพันธุกรรม / มหานครเซลล์ / ด่านศุลกากรเซลล์** จึงดูได้จาก `dashboard.html` หน้าเดิม

| กำกับแถวของเกมนี้ | ค่า |

| คอลัมน์ `game` | `respiration` |
| คอลัมน์ `level` | 31–36 (ด่าน 1–6) — ไม่ชนกับพันธุกรรม 1–7, เซลล์ 11–16, ลำเลียงสาร 21–26 |

- เข้าร่วมห้องทีหลังก็ได้ ดาวที่เก็บไว้ก่อนหน้าจะถูกส่งตามไปให้ครูทันที
- คีย์ใน `localStorage` ขึ้นต้นด้วย `resp-` จึงแยกขาดจากเกมอื่น

## เกียรติบัตร

เล่นครบทั้ง 6 ด่าน **และ** ได้ดาวรวมถึงเกณฑ์ 60% (11 จาก 18 ดาว) → การ์ด “เกียรติบัตร” บนหน้าแผนที่จะปลดล็อก
นักเรียนพิมพ์ชื่อ–นามสกุล แล้วกดบันทึกเป็นไฟล์ภาพ `.png` ได้เลย

- พื้นหลังใช้ไฟล์ **`cert-bg.png`** ในโฟลเดอร์นี้ — เปลี่ยนแบบเกียรติบัตรได้โดยอัปโหลดทับไฟล์เดิม (ชื่อไฟล์เดิม)
- ตำแหน่ง/ขนาด/สีของชื่อปรับได้ที่ค่า `CERT` ใน `index.html` จุดเดียว (ค่าเป็นสัดส่วน 0–1 ของภาพ จึงใช้ภาพขนาดใดก็ได้)
- ถ้าลืมวาง `cert-bg.png` เกมจะวาดกรอบสำรองให้แทน ไม่พัง

## ปรับตัวเลข ATP ให้ตรงกับหนังสือที่ใช้สอน

ด่าน 5 (ห้องบัญชีพลังงาน) คำนวณทุกอย่างจากบล็อก `ATP_BOOK` ใน `index.html` จุดเดียว

```js
const ATP_BOOK = {
  glycoATP: 2, krebsATP: 2,          // ATP โดยตรง
  nadhTotal: 10, fadhTotal: 2,       // ตัวพาอิเล็กตรอนต่อกลูโคส 1 โมเลกุล
  perNADH_trad: 3,  perFADH2_trad: 2,   // ค่าดั้งเดิม (ได้ 38 / 36)
  perNADH_mod: 2.5, perFADH2_mod: 1.5,  // ค่าปัจจุบัน (ได้ ~30)
  shuttle: 2                          // ต้นทุนขนส่ง NADH ของยูคาริโอต
};
```

แก้ตัวเลขในบล็อกนี้แล้ว **ตารางบัญชี ปุ่มสลับ ภารกิจ คำถาม และข้อความสรุปจะเปลี่ยนตามทั้งหมด**
เช่น ถ้าหนังสือไม่คิดต้นทุนขนส่ง ให้ตั้ง `shuttle: 0` ยอดยูคาริโอตจะกลายเป็น 38 ทันที

## การอัปเดตเวอร์ชัน

`sw.js` แคชไฟล์ไว้ให้เล่นออฟไลน์ **ทุกครั้งที่แก้ `index.html` ให้เปลี่ยนเลขในบรรทัด**
`const CACHE = 'respiration-v4';` เป็น `v5`, `v6` … หนึ่งครั้ง เครื่องนักเรียนจึงจะดึงเวอร์ชันใหม่

> ตั้งแต่ `v2` เป็นต้นไป `sw.js` ดึง `index.html` จาก **เครือข่ายก่อนเสมอ** (ออฟไลน์ค่อยใช้ของในแคช)
> นักเรียนจึงได้เวอร์ชันล่าสุดทันทีที่รีเฟรช ไม่ค้างหน้าเก่าเหมือนเดิม
