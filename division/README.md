# 🧬 โรงงานสร้างเซลล์ — เกมการแบ่งเซลล์ (ม.4)

เกมประกอบการเรียนรู้ชีววิทยา ม.4 เล่ม 1 บทที่ 3 **การแบ่งเซลล์** (หัวข้อ 3.5)
ไฟล์เดียวจบ เล่นออฟไลน์ได้ ติดตั้งลงหน้าจอโฮมได้ และส่งคะแนนเข้าแดชบอร์ดครูชุดเดียวกับเกมอื่นในเว็บไซต์นี้

เปิดเล่น: [`index.html`](index.html)

## เนื้อหาในเกม

| ด่าน | ชื่อด่าน | สิ่งที่ได้เรียนรู้ |
|---|---|---|
| 1 | ห้องเก็บพิมพ์เขียว | โครมาทิน · โครโมโซม · ซิสเตอร์โครมาทิด · เซนโทรเมียร์ · ไคนีโทคอร์ (ติดป้ายบนแผนภาพ) |
| 2 | ห้องนับโครโมโซม | ดิพลอยด์ 2n · แฮพลอยด์ n · ฮอมอโลกัสโครโมโซม · ออโตโซมและโครโมโซมเพศ |
| 3 | วัฏจักรเซลล์ | อินเตอร์เฟส G₁ · S · G₂ แล้วเข้าสู่ระยะ M และการแบ่งไซโทพลาซึม |
| 4 | สายพานไมโทซิส | โพรเฟส เมทาเฟส แอนาเฟส เทโลเฟส + การแบ่งไซโทพลาซึมของเซลล์พืชและสัตว์ |
| 5 | สายการผลิตเซลล์สืบพันธุ์ | ไมโอซิส I และ II · ครอสซิงโอเวอร์ · การลดจำนวนโครโมโซม (มีเครื่องคำนวณให้ลองปรับค่า 2n) |
| 6 | บอส: ห้องตรวจสอบคุณภาพ | 8 สถานการณ์จริง + ตารางเทียบไมโทซิส–ไมโอซิส |

เก็บดาวได้สูงสุด **18 ดวง** (ด่านละ 3 ดาว) · มีการ์ดคำศัพท์ 37 คำ ไทย–อังกฤษ

อ้างอิงเนื้อหาจากสไลด์ สสวท. *3.5 การแบ่งเซลล์ (1)* และ *(2)* และหนังสือเรียนรายวิชาเพิ่มเติมวิทยาศาสตร์และเทคโนโลยี ชีววิทยา ม.4 เล่ม 1 (ฉบับปรับปรุง พ.ศ. 2560)

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวเกมทั้งหมด (HTML + CSS + JS ในไฟล์เดียว) |
| `manifest.webmanifest` · `sw.js` | ติดตั้งลงหน้าจอโฮมและเล่นแบบออฟไลน์ (PWA) |
| `icon.svg` · `icon-192.png` · `icon-512.png` · `icon-maskable-512.png` · `apple-touch-icon.png` · `favicon-32.png` | ไอคอนแอป/แท็บ |
| `og-cover.png` | ภาพพรีวิวตอนแชร์ลิงก์ใน LINE / Facebook |
| `cert-bg.png` | พื้นหลังเกียรติบัตรของโรงเรียน (เปลี่ยนได้โดยอัปทับไฟล์เดิม) |

> แผนภาพในด่าน 1 เป็นภาพวาด SVG ในตัวเกม จึงไม่ต้องอัปโหลดไฟล์ภาพเพิ่ม

## ระบบชั้นเรียน (ส่งคะแนนเข้าแดชบอร์ดเดิม)

นักเรียนกดปุ่ม “เข้าร่วมชั้นเรียน” บนหน้าแผนที่ แล้วกรอก **รหัสห้องที่ครูให้ (เช่น M401A) + ชื่อ**
จบด่านเมื่อไร คะแนนจะวิ่งเข้าตาราง `scores` ของโปรเจกต์ `vgurqbcbovgeppvdwizr.supabase.co` ดูได้จาก `dashboard.html` หน้าเดิม

| กำกับแถวของเกมนี้ | ค่า |
|---|---|
| คอลัมน์ `game` | `division` |
| คอลัมน์ `level` | 51–56 (ด่าน 1–6) — ไม่ชนกับพันธุกรรม 1–7, เซลล์ 11–16, ลำเลียงสาร 21–26, หายใจ 31–36 |
| `level_name` | เช่น `แบ่งเซลล์ · ด่าน 4 สายพานไมโทซิส` |

- ถ้าไม่เข้าร่วมห้องหรือเน็ตหลุด เกมยังเล่นได้ตามปกติ คะแนนพักไว้ในคิว `div-outbox` แล้วส่งเองเมื่อกลับมาออนไลน์
- เข้าร่วมห้องทีหลังก็ได้ ดาวที่เก็บไว้ก่อนหน้าจะถูกส่งตามไปให้ครู
- คีย์ใน `localStorage` ขึ้นต้นด้วย `div-` จึงแยกขาดจากเกมอื่น

## เกียรติบัตร

เล่นครบทั้ง 6 ด่าน **และ** ได้ดาวรวมถึงเกณฑ์ 60% (11 จาก 18 ดาว) → การ์ด “เกียรติบัตร” บนหน้าแผนที่จะปลดล็อก
นักเรียนพิมพ์ชื่อ–นามสกุล แล้วกดบันทึกเป็นไฟล์ภาพ `.png` ได้เลย

- พื้นหลังใช้ไฟล์ **`cert-bg.png`** ในโฟลเดอร์นี้ — เปลี่ยนแบบได้โดยอัปโหลดทับไฟล์เดิม
- ตำแหน่ง/ขนาด/สีของชื่อปรับได้ที่ค่า `CERT` ใน `index.html` จุดเดียว (เป็นสัดส่วน 0–1 ของภาพ)

## การอัปเดตเวอร์ชัน

`sw.js` แคชไฟล์ไว้ให้เล่นออฟไลน์ **ทุกครั้งที่แก้ `index.html` ให้เปลี่ยนเลขในบรรทัด**
`const CACHE = 'division-v1';` เป็น `v2`, `v3` … หนึ่งครั้ง เครื่องนักเรียนจึงจะดึงเวอร์ชันใหม่

> `sw.js` ดึง `index.html` จาก **เครือข่ายก่อนเสมอ** (ออฟไลน์ค่อยใช้ของในแคช) นักเรียนจึงได้เวอร์ชันล่าสุดทันทีที่รีเฟรช
