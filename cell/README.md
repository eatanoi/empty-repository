# 🏙️ มหานครเซลล์ — เกมโครงสร้างและหน้าที่ของเซลล์ (ม.4)

เกมประกอบการเรียนรู้ชีววิทยา ม.4 หน่วย **เซลล์และการทำงานของเซลล์**
ไฟล์เดียวจบ (`index.html`) ใช้เอนจินและธีมเดียวกับเกม “โรงไฟฟ้าไมโทคอนเดรีย”

## เนื้อหาในเกม

| ด่าน | ชื่อ | สิ่งที่ฝึก |
|---|---|---|
| 1 | สำรวจเซลล์สัตว์ | ติดป้ายออร์แกเนลล์ 8 จุดบนภาพวาดเซลล์สัตว์ (เยื่อหุ้มเซลล์ · นิวเคลียส · ER หยาบ/เรียบ · กอลจิ · ไลโซโซม · ไมโทคอนเดรีย · เซนทริโอล) |
| 2 | สำรวจเซลล์พืช | ติดป้าย 7 จุด (ผนังเซลล์ · แวคิวโอลกลาง · คลอโรพลาสต์ · พลาสโมเดสมาตา …) แล้วแยก 10 โครงสร้างว่ามีเฉพาะพืช / เฉพาะสัตว์ / ทั้งคู่ |
| 3 | เส้นทางส่งโปรตีน | เรียง 8 ขั้นของระบบเยื่อหุ้มภายใน: นิวเคลียส → ไรโบโซมบน ER หยาบ → กอลจิ → ถุงหลั่ง → เอกโซไซโทซิส |
| 4 | จับคู่หน้าที่ในเมือง | จับคู่ 10 ออร์แกเนลล์กับหน้าที่ผ่านอุปมาหน่วยงานในเมือง (โรงไฟฟ้า · ศูนย์ไปรษณีย์ · โรงกำจัดขยะ …) |
| 5 | ห้องเทียบชนิดเซลล์ | สลับส่องแบคทีเรีย/พืช/สัตว์ อ่านตารางเปรียบเทียบ 10 โครงสร้างและขนาด พร้อม 3 ภารกิจ |
| 6 | บอส: เซลล์ปริศนา | 6 สถานการณ์จริง — เซลล์ตับ · เซลล์หลั่งอินซูลิน · เม็ดเลือดขาว · กล้ามเนื้อหัวใจ · ผักเหี่ยว · เอนโดซิมไบโอซิส |
| + | การ์ดคำศัพท์ | 36 คำ ไทย–อังกฤษ พร้อมนิยาม (แยก 6 หมวด · สลับการ์ดได้) |

ความก้าวหน้า (ดาว/XP) เก็บใน `localStorage` คีย์ `cell-structure-quest-v1` ซึ่ง**แยกจากเกมอื่น**

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวเกมทั้งหมด (HTML + CSS + JS ในไฟล์เดียว) — ภาพเซลล์วาดด้วย SVG ในตัว ไม่ต้องพึ่งไฟล์ภาพภายนอก |
| `manifest.webmanifest` · `sw.js` | ติดตั้งลงหน้าจอโฮมและเล่นแบบออฟไลน์ (PWA) |
| `icon.svg` · `icon-192.png` · `icon-512.png` · `icon-maskable-512.png` · `apple-touch-icon.png` · `favicon-32.png` | ไอคอนแอป/แท็บ |
| `og-cover.png` | ภาพพรีวิวตอนแชร์ลิงก์ใน LINE / Facebook |

## ภาพประกอบที่ใส่เพิ่มได้ (ไม่ใส่ก็เล่นได้ปกติ)

| ไฟล์ที่วางเพิ่มได้ | ใช้ที่ไหน | ถ้าไม่มีจะเป็นอย่างไร |
|---|---|---|
| `imag/stage-animal.webp`, `stage-plant.webp`, `stage-road.webp`, `stage-jobs.webp`, `stage-lab.webp`, `stage-boss.webp` | ไอคอนของ 6 ด่าน | แสดงอิโมจิแทน |
| `logo.png` | โลโก้ Biology. หัวหน้าแรกและท้ายหน้า | ซ่อนรูป เหลือแต่ตัวอักษร |
| `imag/bg.webp` | ภาพพื้นหลังจาง ๆ | ใช้พื้นหลังไล่สีอย่างเดียว |

> ภาพเซลล์สัตว์และเซลล์พืชในด่าน 1–2 **วาดด้วย SVG ในโค้ดโดยตรง** จึงคมชัดทุกขนาดหน้าจอและไม่ต้องอัปไฟล์ภาพเพิ่ม
> ถ้าต้องการเปลี่ยนเป็นภาพถ่าย/ภาพวาดของตัวเอง ต้องขยับพิกัด `ax`/`ay` ของแต่ละป้ายให้ตรงกับภาพใหม่ (ระบบพิกัดคือ 1200×800)

## ระบบชั้นเรียน (ตัวเลือก)

ใช้ Supabase ชุดเดียวกับเกมการหายใจระดับเซลล์ (RPC `check_class`, `submit_progress`, `get_class_questions`)
แต่คีย์ใน `localStorage` ขึ้นต้นด้วย `cell-` จึงเข้าห้องแยกจากเกมอื่นได้ · ไม่เข้าร่วมห้องก็เล่นได้ครบทุกด่าน

## การอัปเดตเวอร์ชัน

ทุกครั้งที่แก้ `index.html` ให้เปลี่ยนเลขในบรรทัด `const CACHE = 'cell-v1';` ของ `sw.js` เป็น `v2`, `v3` …
เครื่องนักเรียนจึงจะดึงเวอร์ชันใหม่แทนของที่แคชไว้
