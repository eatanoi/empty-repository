# 🐾 สถานีวิจัยพฤติกรรมสัตว์ — เกมพฤติกรรมของสัตว์ (ม.6)

เกมประกอบการเรียนรู้ชีววิทยา ม.6 เล่ม 5 **บทที่ 22 พฤติกรรมของสัตว์**
ครอบคลุมหัวข้อ 22.1 การศึกษาพฤติกรรม · 22.2 กลไกการเกิดพฤติกรรม · 22.3 ประเภทพฤติกรรม ·
22.4 ความสัมพันธ์ระหว่างพฤติกรรมกับวิวัฒนาการของระบบประสาท · 22.5 การสื่อสารระหว่างสัตว์

ไฟล์เดียวจบ เล่นออฟไลน์ได้ ติดตั้งลงหน้าจอโฮมได้ และส่งคะแนนเข้าแดชบอร์ดครูชุดเดียวกับเกมอื่นในเว็บไซต์นี้

เปิดเล่น: [`index.html`](index.html)

## ระบบชั้นเรียน (ส่งคะแนนเข้าแดชบอร์ดเดิม)

นักเรียนกดปุ่ม “เข้าร่วมชั้นเรียน” บนหน้าแผนที่ แล้วกรอก **รหัสห้องที่ครูให้ (เช่น M601A) + ชื่อ**
จบด่านเมื่อไร คะแนนจะวิ่งเข้าตาราง `scores` ของโปรเจกต์ `vgurqbcbovgeppvdwizr.supabase.co` ดูได้จาก `dashboard.html` หน้าเดิม

| กำกับแถวของเกมนี้ | ค่า |
|---|---|
| คอลัมน์ `game` | `behavior` |
| คอลัมน์ `level` | 1–6 (ด่าน 1–6) — แยกจากเกมอื่นด้วยคอลัมน์ `game` |
| `level_name` | เช่น `พฤติกรรมสัตว์ · ด่าน 3 ห้องสัญชาตญาณ` |

- ถ้าไม่เข้าร่วมห้องหรือเน็ตหลุด เกมยังเล่นได้ตามปกติ คะแนนพักไว้ในคิว `beh-outbox` แล้วส่งเองเมื่อกลับมาออนไลน์
- เข้าร่วมห้องทีหลังก็ได้ ดาวที่เก็บไว้ก่อนหน้าจะถูกส่งตามไปให้ครูครบทุกด่าน
- คีย์ใน `localStorage` ขึ้นต้นด้วย `beh-` และความก้าวหน้าเก็บที่ `animal-behavior-quest-v1` จึงแยกขาดจากเกมอื่น

## เกียรติบัตร

เล่นครบทั้ง 6 ด่าน **และ** ได้ดาวรวมถึงเกณฑ์ 60% (11 จาก 18 ดาว) → การ์ด “เกียรติบัตร” บนหน้าแผนที่จะปลดล็อก
นักเรียนพิมพ์ชื่อ–นามสกุล แล้วกดบันทึกเป็นไฟล์ภาพ `.png` ได้เลย

> ⚠️ **ยังไม่มีไฟล์ `cert-bg.png` ในโฟลเดอร์นี้** ตอนนี้เกมจึงวาด**กรอบเกียรติบัตรสำรอง**ให้อัตโนมัติ
> ซึ่งใช้งานได้ปกติแต่ไม่มีตราและลายเซ็นของโรงเรียน
>
> เกียรติบัตรของแต่ละเกมมี**ข้อความชื่อหน่วย/เรื่องพิมพ์อยู่ในตัวภาพ** จึงใช้ไฟล์ของเกมอื่นแทนกันไม่ได้
> (ถ้าเอาของเกมสืบพันธุ์มาใช้ เกียรติบัตรจะขึ้นว่า “การสืบพันธุ์ของมนุษย์”)
> เมื่อทำไฟล์ของบทนี้เสร็จแล้ว ให้อัปโหลดชื่อ `cert-bg.png` ลงโฟลเดอร์นี้ แล้วเพิ่ม `'./cert-bg.png'`
> กลับเข้าไปในรายการ `ASSETS` ของ `sw.js` ด้วย

- ตำแหน่ง/ขนาด/สีของชื่อปรับได้ที่ค่า `CERT` ใน `index.html` จุดเดียว (เป็นสัดส่วน 0–1 ของภาพ)
- ข้อความบนกรอบสำรองอยู่ในฟังก์ชัน `certFallback()` — ตอนนี้เขียนว่า *บทที่ 22 เรื่อง “พฤติกรรมของสัตว์”*

## การอัปเดตเวอร์ชัน

`sw.js` แคชไฟล์ไว้ให้เล่นออฟไลน์ **ทุกครั้งที่แก้ `index.html` ให้เปลี่ยนเลขในบรรทัด**
`const CACHE = 'behavior-v1';` เป็น `v2`, `v3` … หนึ่งครั้ง เครื่องนักเรียนจึงจะดึงเวอร์ชันใหม่

> `sw.js` ดึง `index.html` จาก **เครือข่ายก่อนเสมอ** (ออฟไลน์ค่อยใช้ของในแคช) นักเรียนจึงได้เวอร์ชันล่าสุดทันทีที่รีเฟรช
