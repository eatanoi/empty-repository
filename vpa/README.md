## ข้อมูลเก็บที่ไหน

**ค่าเริ่มต้น: เก็บในเบราว์เซอร์ของเครื่องที่ใช้เท่านั้น** (localStorage) ไม่มีการส่งข้อมูลออกไปที่ใด
พิมพ์เสร็จระบบบันทึกให้เองอัตโนมัติ ไม่ต้องกดบันทึก

ข้อควรระวัง

- ล้างข้อมูลเบราว์เซอร์ = ข้อมูลหายทั้งหมด · ควรกด **ส่งออกไฟล์ JSON** เก็บไว้เป็นระยะ
- เบราว์เซอร์ส่วนใหญ่จำกัดพื้นที่ราว 5 MB ต่อเว็บไซต์หนึ่งแห่ง แท็บข้อมูลจะแสดงพื้นที่ที่ใช้ไป
  ภาพที่แนบถูกย่อเหลือด้านยาวไม่เกิน 1200 พิกเซลและบีบอัดเป็น JPEG แล้ว แต่ถ้าแนบภาพมากก็ยังเต็มได้
  ถ้าใกล้เต็มให้เก็บภาพไว้ใน Google Drive แล้วใส่เป็น **ลิงก์หลักฐาน** แทนการแนบไฟล์

## ซิงก์ขึ้น Supabase (ไม่บังคับ)

ทำให้เปิดข้อมูลชุดเดียวกันได้จากหลายเครื่อง ใช้โปรเจกต์ Supabase เดียวกับแดชบอร์ดเกมได้เลย

1. Supabase → **SQL Editor** → วางเนื้อหาจาก [`../supabase/vpa-schema.sql`](../supabase/vpa-schema.sql) → **Run**
2. เปิดแท็บ **ข้อมูลและการซิงก์** → กรอก Project URL, anon public key, อีเมลและรหัสผ่านครู → **เชื่อมต่อ**
3. กด **ส่งข้อมูลขึ้นเซิร์ฟเวอร์** เมื่อทำงานเสร็จในแต่ละวัน · กด **ดึงข้อมูลจากเซิร์ฟเวอร์** เมื่อเปิดจากเครื่องอื่น

ใช้ **anon public key** เท่านั้น ห้ามใช้ `service_role` key · นโยบาย RLS ในไฟล์ SQL กำหนดให้
แต่ละบัญชีเห็นและแก้ไขได้เฉพาะข้อมูลของตัวเอง

การซิงก์เป็นแบบกดเอง ไม่ได้รวมข้อมูลอัตโนมัติ — ถ้าแก้จากสองเครื่องพร้อมกัน
ฝั่งที่กดส่งทีหลังจะเขียนทับของเดิม

## โครงสร้างตัวชี้วัด

ส่วนที่ 1 ใช้ตัวชี้วัดตามมาตรฐานตำแหน่งครู 15 ตัวชี้วัด 3 ด้าน
(ด้านการจัดการเรียนรู้ 8 · ด้านการส่งเสริมและสนับสนุนการจัดการเรียนรู้ 4 · ด้านการพัฒนาตนเองและวิชาชีพ 3)

คะแนนเต็มตั้งค่าเริ่มต้นไว้ที่องค์ประกอบที่ 1 = 60 คะแนน องค์ประกอบที่ 2 = 40 คะแนน
ตัวชี้วัดละ 4 ระดับ และเกณฑ์ผ่าน 70 คะแนน **ทุกค่าปรับได้ในแท็บประเมิน**
ก่อนใช้งานจริงให้ตรวจสอบกับแบบประเมินของสถานศึกษาและหลักเกณฑ์ที่ ก.ค.ศ. กำหนดอีกครั้ง
