🔐 เข้าสู่ระบบครู

ใช้บัญชีที่สร้างไว้ใน Supabase → Authentication → Users

Project URL และ anon key อยู่ที่ Supabase → Project Settings → Data API · ข้อมูลการเข้าสู่ระบบเก็บไว้ในเบราว์เซอร์เครื่องนี้เท่านั้น

ข้อมูลอ่านจาก Supabase ของคุณโดยตรง · หน้านี้ไม่ส่งข้อมูลไปที่อื่นเลย
