# 🚪 ด่านศุลกากรเซลล์ — เกมการลำเลียงสารเข้าและออกจากเซลล์ (ม.4)

เกมประกอบการเรียนรู้ชีววิทยา ม.4 หน่วย **เซลล์และการทำงานของเซลล์** เรื่องการลำเลียงสารผ่านเยื่อหุ้มเซลล์
ไฟล์เดียวจบ (`index.html`) ใช้เอนจินและธีมเดียวกับเกม “มหานครเซลล์” และ “โรงไฟฟ้าไมโทคอนเดรีย”

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | หน้าที่ |

| `index.html` | ตัวเกมทั้งหมด — ภาพเยื่อหุ้มเซลล์และเซลล์ทุกภาพวาดด้วย SVG ในตัว ไม่ต้องพึ่งไฟล์ภาพภายนอก |
| `manifest.webmanifest` · `sw.js` | ติดตั้งลงหน้าจอโฮมและเล่นออฟไลน์ (PWA) |

## 🖼️ ภาพเยื่อหุ้มเซลล์ของด่าน 1

วางไฟล์ชื่อ **`membrane.png`** ไว้ในโฟลเดอร์นี้ ด่าน 1 จะเปลี่ยนเป็นโหมด **จุดหมายเลขบนภาพจริง** อัตโนมัติ
(ยังไม่วางก็เล่นได้ด้วยภาพวาด SVG ที่มีอยู่แล้วในเกม)

จุดหมายเลข 8 จุดตามลำดับ: ภายนอกเซลล์ · ไกลโคลิพิด · ไกลโคโปรตีน · โปรตีนแทรกในเยื่อ ·
ฟอสโฟลิพิดสองชั้น · คอเลสเตอรอล · ไซโทสเกเลตอน · ภายในเซลล์

ปรับตำแหน่งได้ที่ `MEMB_PHOTO_PARTS` ในไฟล์ `index.html` — `u` คือแนวนอน `v` คือแนวตั้ง
คิดเป็นสัดส่วนของภาพ (0 = ซ้าย/บน, 1 = ขวา/ล่าง) ขยับทีละ `.01` = 1% ของภาพ

> ถ้าภาพที่ใช้มีชื่อโครงสร้างพิมพ์มาบนภาพ (เช่น ภาพจากตำรา) ให้ใส่พิกัดแผ่นปิดใน `MEMB_MASKS`
> เกมจะวางแผ่นสีขาวทับข้อความนั้นให้ ไม่ให้นักเรียนเห็นเฉลย — ปัจจุบันตั้งเป็นค่าว่างไว้เพราะภาพที่ใช้ไม่มีข้อความ

## 🔬 ภาพถ่ายจริงของด่าน 3 (ห้องทดลองออสโมซิส)

วางไฟล์ภาพ 6 ใบไว้ในโฟลเดอร์นี้ ด่าน 3 จะเปลี่ยนจากภาพวาดเป็นภาพถ่ายจริงอัตโนมัติ
(ใบไหนยังไม่มี ช่องนั้นจะใช้ภาพวาด SVG แทน — ใส่ครบหรือไม่ครบก็เล่นได้)

| ชื่อไฟล์ | ใช้เมื่อเลือก |
|---|---|
| `osmo-animal-hypo` | เซลล์สัตว์ + ไฮโพโทนิก (เม็ดเลือดแดงบวม–แตก) |
| `osmo-animal-iso` | เซลล์สัตว์ + ไอโซโทนิก (รูปร่างปกติ) |
| `osmo-animal-hyper` | เซลล์สัตว์ + ไฮเปอร์โทนิก (เหี่ยวย่น crenation) |
| `osmo-plant-hypo` | เซลล์พืช + ไฮโพโทนิก (เต่ง) |
| `osmo-plant-iso` | เซลล์พืช + ไอโซโทนิก (อ่อนตัว) |
| `osmo-plant-hyper` | เซลล์พืช + ไฮเปอร์โทนิก (พลาสโมไลซิส) |

นามสกุลเป็น `.jpg` หรือ `.png` ก็ได้ เกมจะหาให้เอง (ลอง `.jpg` ก่อน)
ถ้าใส่ภาพถ่ายแล้ว คำอธิบายสี (เยื่อหุ้มเซลล์/ผนังเซลล์/แวคิวโอล) จะถูกซ่อนอัตโนมัติ เพราะใช้กับภาพวาดเท่านั้น

## 🏅 เกียรติบัตร

เล่นครบทั้ง 6 ด่านและได้ดาวรวม ≥ 60% (11/18) จะปลดล็อกการ์ดเกียรติบัตร → กรอกชื่อ → บันทึกเป็นรูปภาพ
วางไฟล์เกียรติบัตรเปล่าชื่อ `cert-bg.png` ไว้ในโฟลเดอร์นี้ (ยังไม่วางก็ใช้กรอบสำรองได้)
ปรับตำแหน่งชื่อได้ที่ค่า `CERT` ในไฟล์ `index.html` (ทุกค่าคิดเป็นสัดส่วนของภาพ)

## ระบบชั้นเรียน

ส่งคะแนนเข้า Supabase ชุดเดียวกับเกมอื่น (ตาราง `scores`) ขึ้นแดชบอร์ดครูหน้าเดิมได้ทันที

- แถวของเกมนี้กำกับด้วย `game = 'transport'` และเลขด่าน **21–26**
- ต้องมีคอลัมน์ `game` ในตาราง `scores` แล้ว (`alter table public.scores add column if not exists game text;`)
- นักเรียนกดชิป “🏫 เข้าร่วมชั้นเรียน” บนหน้าแผนที่ → กรอกรหัสห้อง + ชื่อ
- เน็ตหลุดคะแนนพักไว้ใน `transport-outbox` แล้วส่งเองเมื่อกลับมาออนไลน์
