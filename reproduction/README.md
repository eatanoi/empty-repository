# 👶 ภารกิจสืบสายชีวิต — เกมการสืบพันธุ์ของมนุษย์ (ม.6)

เกมประกอบการเรียนรู้ชีววิทยา ม.6 เล่ม 5 บทที่ 21 **ระบบสืบพันธุ์และการเจริญเติบโต**
หัวข้อ 21.2 การสืบพันธุ์ของมนุษย์ (21.2.1 ระบบสืบพันธุ์เพศชาย · 21.2.2 ระบบสืบพันธุ์เพศหญิง)

ไฟล์เดียวจบ เล่นออฟไลน์ได้ ติดตั้งลงหน้าจอโฮมได้ และส่งคะแนนเข้าแดชบอร์ดครูชุดเดียวกับเกมอื่นในเว็บไซต์นี้

เปิดเล่น: [`index.html`](index.html)

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | หน้าที่ |

| `female-repro.png` | ภาพแผนภาพระบบสืบพันธุ์เพศหญิงที่ใช้ในด่าน 4 (1020 × 1697) — ภาพตัดด้านข้าง (บน) และภาพด้านหน้าที่ผ่ามดลูกกับรังไข่ (ล่าง) |
| `cert-bg.png` | พื้นหลังเกียรติบัตรของโรงเรียน (2000 × 1414) — เปลี่ยนได้โดยอัปทับไฟล์เดิม |

> ด่าน 1 ใช้ไฟล์ `male-repro.png` และด่าน 4 ใช้ `female-repro.png`
> ทั้งสองด่านมีภาพวาด SVG ในตัวเกมเป็น**ภาพสำรอง**ให้อัตโนมัติถ้าไฟล์หาย

ด่าน 1 ไม่ได้ใช้ทั้งไฟล์ แต่ **ครอบตัดด้วย CSS ตอนแสดงผล** (ไม่แก้ไฟล์ต้นฉบับ) เป็น 2 กรอบ

| ค่าใน `index.html` | ใช้ทำอะไร |
|---|---|
| `IMG_W`, `IMG_H` | ขนาดจริงของไฟล์ (1200 × 1150) |
| `CROP_MAIN` | ช่วงอัณฑะ–องคชาต–ภาพขยาย ใช้เป็นกระดานติดป้าย (ซูมเข้ามาเพราะถ้าใช้ทั้งภาพ จุดยึดของอัณฑะ ถุงอัณฑะ และหลอดเก็บอสุจิ จะห่างกันไม่ถึง 20 px บนมือถือ จนแตะเลือกไม่ได้) |
| `CROP_TUBE` | เฉพาะกรอบภาพขยายอัณฑะ — ใช้ประกอบคำถามช่วงที่ 2 |

**ถ้าเปลี่ยนไฟล์ `male-repro.png` เป็นภาพใหม่** ต้องแก้ค่าเหล่านี้ตามภาพใหม่ แล้วปรับ `u,v` ใน
`MALE_PHOTO_PARTS` ซึ่งคิดเป็นสัดส่วน 0–1 **ของกรอบ `CROP_MAIN` ที่ครอบตัดแล้ว**
(`u = (x − CROP_MAIN.x) / CROP_MAIN.w` · `v = (y − CROP_MAIN.y) / CROP_MAIN.h` เมื่อ x, y เป็นพิกเซลบนไฟล์)

## ระบบชั้นเรียน (ส่งคะแนนเข้าแดชบอร์ดเดิม)

นักเรียนกดปุ่ม “เข้าร่วมชั้นเรียน” บนหน้าแผนที่ แล้วกรอก **รหัสห้องที่ครูให้ (เช่น M601A) + ชื่อ**
จบด่านเมื่อไร คะแนนจะวิ่งเข้าตาราง `scores` ของโปรเจกต์ `vgurqbcbovgeppvdwizr.supabase.co` ดูได้จาก `dashboard.html` หน้าเดิม

| กำกับแถวของเกมนี้ | ค่า |
|---|---|
| คอลัมน์ `game` | `reproduction` |
| คอลัมน์ `level` | 1–6 (ด่าน 1–6) — แยกจากเกมอื่นด้วยคอลัมน์ `game` |
| `level_name` | เช่น `สืบพันธุ์ · ด่าน 3 สายพานสร้างสเปิร์ม` |

- ถ้าไม่เข้าร่วมห้องหรือเน็ตหลุด เกมยังเล่นได้ตามปกติ คะแนนพักไว้ในคิว `repro-outbox` แล้วส่งเองเมื่อกลับมาออนไลน์
- เข้าร่วมห้องทีหลังก็ได้ ดาวที่เก็บไว้ก่อนหน้าจะถูกส่งตามไปให้ครูครบทุกด่าน
- คีย์ใน `localStorage` ขึ้นต้นด้วย `repro-` จึงแยกขาดจากเกมอื่น

## เกียรติบัตร

เล่นครบทั้ง 6 ด่าน **และ** ได้ดาวรวมถึงเกณฑ์ 60% (11 จาก 18 ดาว) → การ์ด “เกียรติบัตร” บนหน้าแผนที่จะปลดล็อก
นักเรียนพิมพ์ชื่อ–นามสกุล แล้วกดบันทึกเป็นไฟล์ภาพ `.png` ได้เลย

- พื้นหลังใช้ไฟล์ **`cert-bg.png`** ในโฟลเดอร์นี้ — เปลี่ยนแบบได้โดยอัปโหลดทับไฟล์เดิม
- ตำแหน่งชื่อ (`CERT.nameX/nameY`) วัดจากกึ่งกลางกล่องสีขาวในไฟล์นี้แล้ว ชื่อจึงลงกรอบพอดี
- ถ้าไฟล์หาย เกมจะวาดกรอบเกียรติบัตรสำรองให้อัตโนมัติ เล่นต่อได้ตามปกติ
- ตำแหน่ง/ขนาด/สีของชื่อปรับได้ที่ค่า `CERT` ใน `index.html` จุดเดียว (เป็นสัดส่วน 0–1 ของภาพ)

## การอัปเดตเวอร์ชัน

`sw.js` แคชไฟล์ไว้ให้เล่นออฟไลน์ **ทุกครั้งที่แก้ `index.html` ให้เปลี่ยนเลขในบรรทัด**
`const CACHE = 'reproduction-v6';` เป็น `v7`, `v8` … หนึ่งครั้ง เครื่องนักเรียนจึงจะดึงเวอร์ชันใหม่

> `sw.js` ดึง `index.html` จาก **เครือข่ายก่อนเสมอ** (ออฟไลน์ค่อยใช้ของในแคช) นักเรียนจึงได้เวอร์ชันล่าสุดทันทีที่รีเฟรช
