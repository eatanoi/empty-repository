# ⚛️ โรงเชื่อมอิเล็กตรอน — เกมพันธะโคเวเลนต์ (เคมี ม.4)

เกมประกอบการเรียนรู้เคมี ม.4 บท **พันธะเคมี** หัวข้อ **พันธะโคเวเลนต์**
(การเกิดพันธะ · ชนิดของพันธะ · สูตรและการเรียกชื่อ · ความยาว/พลังงานพันธะ · สมบัติของสารโคเวเลนต์)

ไฟล์เดียวจบ เล่นออฟไลน์ได้ ติดตั้งลงหน้าจอโฮมได้ และส่งคะแนนเข้าแดชบอร์ดครูชุดเดียวกับเกมอื่นในเว็บไซต์นี้

เปิดเล่น: [`index.html`](index.html)

### ห้องประกอบโมเลกุล (ด่าน 2)

ช่วงแรกของด่าน 2 เป็นซิมูเลเตอร์ **3 มิติ** ไม่ใช่ข้อสอบ นักเรียน**ลาก**ชิ้นพันธะจากถาดไปวางบนช่องระหว่างอะตอม
(บนมือถือ **แตะเลือกชิ้นพันธะ แล้วแตะช่อง** ก็ได้ · ชิ้นที่เลือกจะค้างไว้ วางติดกันหลายพันธะได้เลย)
มีปุ่ม **✕ ลบพันธะ** ให้แก้ที่วางผิดได้ตลอด และ**ลากที่ตัวภาพเพื่อหมุนดูโมเลกุลรอบด้าน**

พิกัดอะตอมเป็นรูปทรงจริงตามที่เรียน นักเรียนจึงเห็นว่า CH₄ เป็น**ทรงสี่หน้า** ไม่ใช่กากบาทแบน ·
H₂O เป็น**มุมงอ** · CO₂ กับ HCN เป็น**เส้นตรง** และเมื่อประกอบสำเร็จเกมจะบอกชื่อรูปร่างกับมุมพันธะให้
(เชื่อมไปยังเรื่องรูปร่างโมเลกุลที่จะเรียนต่อ)

ภาพ 3 มิติวาดด้วยตัวฉายภาพที่เขียนไว้ในไฟล์เกมเอง **ไม่ได้ใช้ไลบรารีภายนอก** เกมจึงยังเล่นออฟไลน์ได้
วิธีวาดคือหมุนพิกัดรอบแกน Y แล้วแกน X ฉายภาพแบบมีเปอร์สเปกทีฟ แล้วเรียงทุกชิ้นตามความลึกก่อนวาด
(painter's algorithm) ชิ้นที่อยู่ใกล้กล้องจึงบังชิ้นที่อยู่ไกลถูกต้อง

เกมไม่ได้เช็คว่า "ตรงเฉลยไหม" แต่**คำนวณอิเล็กตรอนรอบอะตอมจริง ๆ** ตามกติกา

```
อิเล็กตรอนรอบอะตอม = เวเลนซ์อิเล็กตรอน + ผลรวมลำดับพันธะที่ต่อกับอะตอมนั้น
อิเล็กตรอนที่ยังไม่ได้ใช้ = เวเลนซ์อิเล็กตรอน − ผลรวมลำดับพันธะ   (วาดเป็นจุดสีแดงรอบอะตอม)
```

ตัวเลขใต้อะตอมจะอัปเดตทุกครั้งที่วางหรือลบพันธะ และขึ้น ✓ สีเขียวเมื่อครบ
(ไฮโดรเจนครบที่ 2 · อะตอมอื่นครบที่ 8) เมื่อวางครบทุกช่อง**และ**ทุกอะตอมครบออกเตตจึงจะผ่าน
ถ้ายังไม่ครบ เกมจะบอกว่าอะตอมไหนขาดหรือเกินกี่อิเล็กตรอน นักเรียนจึงแก้เองได้โดยไม่ต้องเดา

### ห้องวัดพันธะ (ด่าน 4)

จับคู่ **12 พันธะ** กับความยาวพันธะ แบ่งสองรอบ — พันธะของคาร์บอน 6 แล้วพันธะของ N กับ O 6
การ์ดแสดง**แค่ตัวเลขความยาว** พลังงานพันธะกับคำอธิบายเปิดหลังตอบถูก

> ภายในรอบเดียวกัน **ความยาวพันธะต้องไม่ซ้ำกัน** ไม่งั้นจะจับคู่ได้มากกว่าหนึ่งคำตอบ

สองจุดที่ตั้งใจให้สะดุด

- **ขนาดอะตอมก็กำหนดความยาวพันธะ** ไม่ใช่แค่จำนวนคู่ที่ใช้ร่วมกัน — C–H 109 < C–O 143 < C–N 147 < C–C 154 pm ทั้งที่เป็นพันธะเดี่ยวเหมือนกัน
- **N–N (163) กับ O–O (146) อ่อนผิดคาด** เพราะคู่โดดเดี่ยวบนสองอะตอมผลักกันเอง หักล้างความเข้าใจว่าพันธะเดี่ยวของทุกธาตุแข็งแรงพอ ๆ กัน

ช่วงเรียงลำดับพลังงานพันธะมี 7 ชิ้น จงใจใส่ O–O กับ N–N ไว้ต้นแถว

### คลังสมบัติสาร (ด่าน 5)

แยกสมบัติ **14 ข้อ** ลงกล่องโมเลกุลกับกล่องโครงร่างตาข่าย แล้วจับคู่สารโครงร่างตาข่าย **6 ชนิด**
— เพชร · แกรไฟต์ · ควอตซ์ (SiO₂) · ซิลิคอนคาร์ไบด์ (SiC) · โบรอนไนไตรด์ (BN) · ซิลิคอน (Si)

การ์ดแสดง**คำใบ้โครงสร้าง** (เช่น "ซิลิคอนสลับกับคาร์บอน โครงสร้างแบบเดียวกับเพชร") ต้องบอกให้ได้ว่าเป็นสารใด

### ห้องตั้งชื่อสาร (ด่าน 3)

จับคู่สูตรกับชื่อ **15 สาร** แบ่งสองรอบ — ปานกลาง 8 สาร แล้วต่อด้วยชุดยาก 7 สาร

**การ์ดแสดงแค่สูตรเท่านั้น** นักเรียนต้องอ่านสูตรแล้วนับจำนวนอะตอมเอง จำนวนอะตอมกับคำอธิบาย
จะเปิดออกมาหลังตอบถูก พร้อมบอกชนิดพันธะในโมเลกุลนั้นด้วย

| รอบ | สาร | จุดที่ต้องระวัง |
|---|---|---|
| ปานกลาง | CO | ธาตุแรก 1 อะตอม **ไม่ใส่ “มอนอ”** · พันธะสาม C≡O |
| ปานกลาง | SO₃ · CS₂ | CS₂ ลงท้าย **ซัลไฟด์** ไม่ใช่ “ซัลเฟอร์ไรด์” |
| ปานกลาง | N₂O · N₂O₄ · N₂O₅ | สามตัวนี้ต่างกันแค่จำนวนออกซิเจน ต้องนับให้ดี |
| ปานกลาง | PCl₅ · SF₆ | ข้อยกเว้นออกเตตแบบ**เกิน** 8 |
| ยาก | OF₂ | ดักคนจำผิด — ฟลูออรีนมี EN สูงกว่า ออกซิเจนจึงอยู่**หน้า** |
| ยาก | S₂Cl₂ | ใส่ “ได” **ทั้งสองธาตุ** |
| ยาก | Cl₂O₇ · I₂O₅ | คำอุปสรรคเลข 7 (เฮปตะ) |
| ยาก | P₄O₁₀ | เลขใหญ่สุด — เตตระ + **เดคะ** (10) |
| ยาก | XeF₄ | แก๊สมีสกุลก็สร้างสารได้ |
| ยาก | BF₃ | ข้อยกเว้นออกเตตแบบ**ขาด** (รอบโบรอนมี 6) คนละแบบกับ PCl₅ · SF₆ |

ครอบคลุมทั้งพันธะเดี่ยว (11 สาร) · พันธะคู่ (8 สาร) · พันธะสาม (CO และ N₂O)

#### โหมดของกระดานจับคู่

`matchBoard(pairs, hide)` มีสามโหมด เลือกตามว่า "คำใบ้" ในการ์ดนั้นเป็นโจทย์หรือเป็นเฉลย

| `hide` | การ์ดแสดงอะไร | ใช้ที่ไหน |
|---|---|---|
| `'all'` | แสดงแค่หัวการ์ด ซ่อนทั้งคำใบ้และคำอธิบาย | ด่าน 3 (คำใบ้คือจำนวนอะตอม = เฉลย) · ด่าน 4 (คำใบ้คือพลังงานพันธะ) |
| `'desc'` | แสดงคำใบ้ ซ่อนแต่คำอธิบาย | ด่าน 5 (คำใบ้คือโครงสร้างผลึก = โจทย์ ต้องเห็น) |
| ไม่ใส่ | แสดงทั้งหมดตั้งแต่แรก | — |

> ระวังใช้ `'all'` กับการ์ดที่คำใบ้เป็นโจทย์ จะเหลือแต่อิโมจิให้เดา

### กติกาการเขียนตัวเลือกในคำถาม

ตัวเลือกทั้ง 4 ข้อของทุกคำถามเขียนให้**ยาวใกล้เคียงกันและขึ้นต้นด้วยรูปประโยคเดียวกัน**
เพื่อไม่ให้นักเรียนเดาคำตอบจาก “ข้อที่ยาวที่สุด” ได้โดยไม่ต้องรู้เนื้อหา
เหตุผลและตัวเลขประกอบจะอยู่ใน**คำอธิบายหลังตอบ** (`e:`) ไม่ใช่ในตัวเลือก

ถ้าเพิ่มคำถามใหม่ ให้ยึดกติกานี้:

- ตัวเลือกผิดต้องเป็น**ความเข้าใจผิดที่พบจริง** ไม่ใช่ข้อที่ผิดจนเห็นได้ชัด
- ตัวเลือกทั้ง 4 ควรต่างกันที่**คำสำคัญไม่กี่คำ** เช่น สั้น/ยาว · 3 คู่/4 คู่
- กระจายตำแหน่งเฉลย อย่าให้ไปกองอยู่ช่องเดียว

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวเกมทั้งหมด (HTML + CSS + JS ในไฟล์เดียว) |
| `manifest.webmanifest` · `sw.js` | ติดตั้งลงหน้าจอโฮมและเล่นแบบออฟไลน์ (PWA) |
| `icon.svg` · `icon-192.png` · `icon-512.png` · `icon-maskable-512.png` · `apple-touch-icon.png` · `favicon-32.png` | ไอคอนแอป/แท็บ |
| `og-cover.png` | ภาพพรีวิวตอนแชร์ลิงก์ใน LINE / Facebook |
| `cert-bg.png` | พื้นหลังเกียรติบัตรของโรงเรียน (1492 × 1054) — เปลี่ยนได้โดยอัปทับไฟล์เดิม |

## ระบบชั้นเรียน (ส่งคะแนนเข้าแดชบอร์ดเดิม)

นักเรียนกดปุ่ม “เข้าร่วมชั้นเรียน” บนหน้าแผนที่ แล้วกรอก **รหัสห้องที่ครูให้ (เช่น M401A) + ชื่อ**
จบด่านเมื่อไร คะแนนจะวิ่งเข้าตาราง `scores` ของโปรเจกต์ Supabase เดิม ดูได้จาก `dashboard.html` หน้าเดิม

| กำกับแถวของเกมนี้ | ค่า |
|---|---|
| คอลัมน์ `game` | `covalent` |
| คอลัมน์ `level` | 1–6 (ด่าน 1–6) — แยกจากเกมอื่นด้วยคอลัมน์ `game` |
| `level_name` | เช่น `พันธะโคเวเลนต์ · ด่าน 3 ห้องตั้งชื่อสาร` |

- ถ้าไม่เข้าร่วมห้องหรือเน็ตหลุด เกมยังเล่นได้ตามปกติ คะแนนพักไว้ในคิว `cov-outbox` แล้วส่งเองเมื่อกลับมาออนไลน์
- เข้าร่วมห้องทีหลังก็ได้ ดาวที่เก็บไว้ก่อนหน้าจะถูกส่งตามไปให้ครูครบทุกด่าน
- คีย์ใน `localStorage` ขึ้นต้นด้วย `cov-` (และ `covalent-quest-v1` สำหรับความคืบหน้า) จึงแยกขาดจากเกมอื่น

## เกียรติบัตร

เล่นครบทั้ง 6 ด่าน **และ** ได้ดาวรวมถึงเกณฑ์ 60% (11 จาก 18 ดาว) → การ์ด “เกียรติบัตร” บนหน้าแผนที่จะปลดล็อก
นักเรียนพิมพ์ชื่อ–นามสกุล แล้วกดบันทึกเป็นไฟล์ภาพ `.png` ได้เลย

- พื้นหลังใช้ไฟล์ **`cert-bg.png`** ในโฟลเดอร์นี้ — เปลี่ยนแบบได้โดยอัปโหลดทับไฟล์เดิม
- ถ้าไฟล์หาย เกมจะวาด**กรอบเกียรติบัตรสำรอง**ให้อัตโนมัติ เล่นต่อได้ตามปกติ
  > ห้ามคัดลอก `cert-bg.png` จากเกมอื่นมาใช้ เพราะแต่ละไฟล์มี**ชื่อหน่วย/ระดับชั้นพิมพ์ติดอยู่ในภาพ**

**ถ้าเปลี่ยนไฟล์พื้นหลังเป็นแบบใหม่** ต้องวัดตำแหน่ง “แคปซูลใส่ชื่อ” บนไฟล์ใหม่แล้วแก้ค่า `CERT`
ให้ตรง (ทุกค่าคิดเป็นสัดส่วน 0–1 ของภาพ จึงใช้ไฟล์ขนาดใดก็ได้):

| ค่า | ของไฟล์ปัจจุบัน | ความหมาย |
|---|---|---|
| `nameX` | 0.4953 | กึ่งกลางชื่อแนวนอน = กึ่งกลางแคปซูล |
| `nameY` | 0.4388 | กึ่งกลางชื่อแนวตั้ง (ต่ำกว่ากึ่งกลางแคปซูลราว 2.5 px เผื่อวรรณยุกต์ไทยที่กินที่ด้านบน) |
| `nameW` | 0.40 | ความกว้างสูงสุดของชื่อ — ชื่อยาวจะย่อขนาดเองจนพอดี |
| `nameSize` | 0.034 | ขนาดตัวอักษรเทียบกับความกว้างภาพ ต้องไม่สูงเกินแคปซูล |
| `nameColor` | `#FFFFFF` | สีชื่อตอนใช้ภาพของโรงเรียน (แคปซูลพื้นน้ำเงินเข้ม) |
| `nameColorFallback` | `#0A0A0A` | สีชื่อตอนใช้กรอบสำรอง (แคปซูลพื้นอ่อน) |

> ไฟล์ปัจจุบันมีแคปซูลอยู่ที่ x 398–1080 · y 423–497 px (กว้าง 0.457 · สูง 0.070 ของภาพ)

ค่าทั้งหมดอยู่ที่ `CERT` ใน `index.html` จุดเดียว แก้ที่นั่นที่เดียวจบ

## การอัปเดตเวอร์ชัน

`sw.js` แคชไฟล์ไว้ให้เล่นออฟไลน์ **ทุกครั้งที่แก้ `index.html` ให้เปลี่ยนเลขในบรรทัด**
`const CACHE = 'covalent-v8';` เป็น `v9`, `v10` … หนึ่งครั้ง เครื่องนักเรียนจึงจะดึงเวอร์ชันใหม่

> `sw.js` ดึง `index.html` จาก **เครือข่ายก่อนเสมอ** (ออฟไลน์ค่อยใช้ของในแคช) นักเรียนจึงได้เวอร์ชันล่าสุดทันทีที่รีเฟรช
